# Student Performance Prediction Using Linear Regression

## Project Overview
This project explores student performance using Machine Learning techniques. It uses Simple Linear Regression and Multiple Linear Regression to understand how study hours, attendance percentage, and class participation relate to students' total scores.

## Objectives
- Analyze student performance data.
- Explore relationships between study hours and total scores.
- Build a Simple Linear Regression model.
- Build a Multiple Linear Regression model.
- Predict students' total scores.
- Evaluate model performance using regression metrics.

## Technologies Used
- Python
- Google Colab
- Pandas
- Matplotlib
- Scikit-learn

## Topics Covered
- Data loading and exploration
- Data cleaning and missing-value checking
- Data sampling
- Data visualization
- Feature selection
- Train-test split
- Simple Linear Regression
- Multiple Linear Regression
- Model prediction
- Model evaluation using R² Score, Mean Squared Error (MSE), and Mean Absolute Error (MAE)

## Project Files
- `machineLearning_supervised_regression.ipynb` – Jupyter Notebook containing the code and analysis.
- `student_performance.csv` – Dataset used for the analysis, if permitted to share.

## How to Run
1. Download or clone this repository.
2. Open the notebook in Google Colab or Jupyter Notebook.
3. Make sure the dataset is available and update its file path if necessary.
4. Run the notebook cells in order.
